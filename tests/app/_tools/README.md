# App Tools

Helper scripts for app-side test workflows.

## Current scripts
- `it_deploy_temp0.ps1` - deploy selected files to NWN module temp0.
- `it_ingest_screens.ps1` - ingest screenshots into fixture folders.
- `it_report.ps1` - summarize app test outcomes.
- `it_save_jui_from_clipboard.ps1` - save copied JUI payload quickly.
- `it_validate.ps1` - validate fixture structure/content.
- `it_validate_nuiencsync.ps1` - specialized validation for encourage/sync cases.
