# NWN Tools

Tooling helpers for NWN-side test operations.

## Current scripts
- `itnwn_deploy_all_nss.py` - deploy test scripts to module `temp0`.
- `itnwn_deploy_temp0_launchers.ps1` - deploy/generated launcher scripts.
- `itnwn_capture_builder_result.ps1` - capture one builder result.
- `itnwn_capture_all_builder_results.ps1` - batch captures.
- `itnwn_pack_hak.ps1` / `itnwn_pack_hak.mjs` - package test assets into HAK.
- `itnwn_validate.ps1` - validation helper.
- `itnwn_report.ps1` - reporting helper.
