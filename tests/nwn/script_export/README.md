# Script Export Cases

This folder validates script-export flows from builder output to NWN runtime.

## Purpose
- verify generated `.nss` launch scripts
- verify event script wiring
- confirm expected window IDs and open behavior

## Typical contents
- `itnwn_scrxp.nss` script export harness
- `nuitst_scrrun.nss` runner
- `nuitst_screv.nss` event script
- `script_export.jui` expected layout payload
